# 05 — Search available rooms

**What to build:** พนักงานระบุวันที่ ช่วงเวลา และจำนวนผู้เข้าร่วม แล้วเห็นเฉพาะ Room ที่ว่างและจุคนได้พอจริง แทนที่การถามเจ้าหน้าที่ธุรการและเปิดสมุดกระดาษ

**Blocked by:** 02 — Room management, 04 — Business Hours configuration

**Status:** ready-for-agent

- [ ] หน้าค้นหารับวันที่ เวลาเริ่ม เวลาสิ้นสุด และจำนวนผู้เข้าร่วม โดยตั้งค่าเริ่มต้นวันที่เป็นวันปัจจุบัน
- [ ] ผลการค้นหาไม่รวม Room ที่ Capacity น้อยกว่าจำนวนผู้เข้าร่วมที่ระบุ (FR-BKG-02)
- [ ] ผลการค้นหากรองเพิ่มได้ด้วยอาคารและ/หรือชั้น (FR-ROOM-02)
- [ ] ผลการค้นหาไม่รวม Room ที่สถานะปิดการใช้งานชั่วคราว
- [ ] ผลการค้นหาไม่รวม Room ที่มี Booking สถานะยืนยันแล้วซ้อนทับกับช่วงเวลาที่ระบุ (FR-BKG-01)
- [ ] ถ้าช่วงเวลาที่ระบุอยู่นอก Business Hours ระบบแสดงช่วงเวลาทำการที่อนุญาตแทนผลลัพธ์ที่ว่างเปล่าหรือทำให้เข้าใจผิด
- [ ] ถ้าไม่มี Room ตรงเงื่อนไข ระบบแสดงข้อความแนะนำให้ปรับช่วงเวลาหรือจำนวนผู้เข้าร่วม แทนรายการว่างเปล่า
- [ ] มีตาราง Booking ในฐานข้อมูล (ยังว่างเปล่าในขั้นนี้) เพื่อให้ ticket ถัดไปเพิ่มแถวได้โดยไม่ต้อง migrate schema ใหม่

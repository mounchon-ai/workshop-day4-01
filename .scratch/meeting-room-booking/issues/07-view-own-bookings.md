# 07 — View own bookings

**What to build:** พนักงานเลือกชื่อตนเองแล้วดูรายการ Booking ทั้งหมดที่ตนเป็นเจ้าของ เรียงจากใหม่ไปเก่า พร้อมดูรายละเอียดครบของแต่ละรายการ — เป็นจุดตั้งต้นของการแก้ไขและยกเลิก

**Blocked by:** 06 — Create booking with full rule enforcement

**Status:** ready-for-agent

- [ ] หน้าจอบังคับให้เลือกชื่อ Employee (ผ่านช่องพิมพ์ค้นหาเดียวกับตอนจอง) ก่อนจึงแสดงรายการ Booking
- [ ] รายการ Booking ของ Employee ที่เลือกเรียงตามเวลาเริ่มจากใหม่ไปเก่า (FR-BKG-17)
- [ ] กรองรายการให้เห็นเฉพาะ Booking ที่เวลาสิ้นสุดยังไม่ผ่านได้
- [ ] เลือกดูรายละเอียดครบทุกฟิลด์ของ Booking หนึ่งรายการได้ ได้แก่ Room เจ้าของ ช่วงเวลา หัวข้อ จำนวนผู้เข้าร่วม และสถานะ (FR-BKG-18)
- [ ] ถ้า Employee ที่เลือกไม่มี Booking เลย แสดงข้อความแจ้งพร้อมทางไปหน้าค้นหาห้องว่าง แทนตารางว่างเปล่า

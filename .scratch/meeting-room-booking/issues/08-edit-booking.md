# 08 — Edit booking

**What to build:** เจ้าของ Booking แก้ไขช่วงเวลา ห้อง หัวข้อ หรือจำนวนผู้เข้าร่วมได้ โดยระบบตรวจกฎชุดเดียวกับตอนสร้างใหม่ทุกครั้ง ยกเว้นไม่นับช่วงเวลาเดิมของ Booking นั้นเป็น Conflict กับตัวเอง

**Blocked by:** 07 — View own bookings

**Status:** ready-for-agent

- [ ] เฉพาะ Employee ที่เป็นเจ้าของ Booking เท่านั้นที่แก้ไขได้ — คนอื่นที่พยายามแก้ไขถูกปฏิเสธพร้อมข้อความ "แก้ไขได้เฉพาะเจ้าของ" (FR-BKG-12)
- [ ] Booking ที่เวลาสิ้นสุดผ่านไปแล้วแก้ไขไม่ได้ ถูกปฏิเสธพร้อมข้อความชัดเจน
- [ ] แบบฟอร์มแก้ไขแสดงข้อมูลเดิมของ Booking ล่วงหน้า
- [ ] การส่งแก้ไขตรวจความครบถ้วน ความถูกต้องของช่วงเวลา การไม่จองย้อนหลัง Business Hours และ Capacity เหมือนตอนสร้างทุกประการ (FR-BKG-13)
- [ ] การส่งแก้ไขตรวจ Conflict กับ Booking สถานะยืนยันแล้วรายการอื่นของ Room เป้าหมาย แต่ไม่นับ Booking ที่กำลังแก้ไขเป็น Conflict ของตัวเอง (FR-BKG-13)
- [ ] ถ้ากฎข้อใดไม่ผ่าน ข้อมูลเดิมของ Booking คงอยู่ครบถ้วนไม่เปลี่ยนแปลง และแสดงกฎที่ไม่ผ่านเป็นภาษาไทยครบทุกข้อ
- [ ] การแก้ไขที่สำเร็จบันทึกทับข้อมูลใหม่และแสดงผลสำเร็จ
- [ ] การแก้ไขที่สำเร็จบันทึกร่องรอย (audit) หนึ่งรายการ ระบุประเภทการกระทำ Booking ที่เกี่ยวข้อง รหัส Employee ที่ผู้ใช้เลือก และเวลาที่เกิดขึ้น

# 09 — Cancel booking

**What to build:** เจ้าของ Booking ยกเลิกรายการที่ยังไม่ผ่านได้ โดยต้องยืนยันซ้ำก่อนยกเลิกจริง เพื่อคืนช่วงเวลาให้ Room ว่างสำหรับคนอื่น

**Blocked by:** 07 — View own bookings

**Status:** ready-for-agent

- [ ] เฉพาะ Employee ที่เป็นเจ้าของ Booking เท่านั้นที่ยกเลิกได้ — คนอื่นที่พยายามยกเลิกถูกปฏิเสธพร้อมข้อความ "ยกเลิกได้เฉพาะเจ้าของ" (FR-BKG-14)
- [ ] Booking ที่เวลาสิ้นสุดผ่านไปแล้วยกเลิกไม่ได้ ถูกปฏิเสธพร้อมข้อความชัดเจน (FR-BKG-15)
- [ ] การยกเลิกต้องดูรายละเอียด Booking แล้วยืนยันซ้ำอีกครั้งก่อนจึงมีผลจริง
- [ ] ถ้าไม่ยืนยันซ้ำ Booking ไม่เปลี่ยนแปลงใดๆ
- [ ] การยกเลิกที่ยืนยันแล้วเปลี่ยนสถานะ Booking เป็นยกเลิกแล้ว โดยไม่ลบแถวออก
- [ ] Booking ที่ยกเลิกแล้วไม่ถูกนับเป็น Conflict อีกต่อไป ทำให้ช่วงเวลานั้นว่างทันทีในการค้นหาครั้งถัดไป (FR-BKG-16)
- [ ] Booking ที่ถูกยกเลิกไปแล้ว หากพยายามยกเลิกซ้ำ ระบบแจ้งสถานะปัจจุบันโดยไม่เปลี่ยนแปลงข้อมูล
- [ ] การยกเลิกที่สำเร็จบันทึกร่องรอย (audit) หนึ่งรายการ ระบุประเภทการกระทำ Booking ที่เกี่ยวข้อง รหัส Employee ที่ผู้ใช้เลือก และเวลาที่เกิดขึ้น

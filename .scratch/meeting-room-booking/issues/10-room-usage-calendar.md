# 10 — Room usage calendar

**Blocked by:** 06 — Create booking with full rule enforcement

**Status:** ready-for-agent

- [ ] หน้าปฏิทินตั้งค่าเริ่มต้นเป็นวันปัจจุบัน

- [ ] Booking ของวันที่เลือกจัดกลุ่มตาม Room และเรียงตามเวลาเริ่มภายในแต่ละห้อง (FR-BKG-03)

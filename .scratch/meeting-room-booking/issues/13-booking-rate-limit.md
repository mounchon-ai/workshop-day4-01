# 13 — Booking-creation rate limit

**What to build:** ระบบป้องกันตัวเองจากปริมาณคำขอที่ผิดปกติบน endpoint เดียวที่เขียนสถานะใหม่ภายใต้การแย่งชิง (การสร้าง Booking) เพื่อไม่ให้กฎ Conflict ถูกเอาชนะด้วยการยิงคำขอถี่เกินไป

**Blocked by:** 06 — Create booking with full rule enforcement

**Status:** ready-for-agent

- [ ] คำขอสร้าง Booking ถูกนับแยกตามหมายเลข IP ต้นทางภายในช่วงเวลาเลื่อน (rolling window) 1 นาที
- [ ] คำขอสร้าง Booking ลำดับที่ 31 ขึ้นไปจาก IP เดียวกันภายใน 1 นาที ถูกปฏิเสธด้วยรหัส 429 ส่วน 30 คำขอแรกทำงานตามปกติ (IR-13, NFR-SEC-03)
- [ ] Rate limit นี้ใช้เฉพาะกับการสร้าง Booking เท่านั้น ไม่กระทบ endpoint สำหรับอ่านข้อมูล (ค้นหา, ปฏิทิน, รายการ)
- [ ] ตัวนับรีเซ็ตอย่างเหมาะสม ผู้ใช้ที่คำขอไม่เกินเกณฑ์ไม่ได้รับผลกระทบใดๆ

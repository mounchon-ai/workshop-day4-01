| หัวข้อ | รายละเอียด |
|---|---|
| ชื่อระบบ | ระบบจองห้องประชุม (Meeting Room Booking) |
| เวอร์ชันเอกสาร | 0.2 |
| วันที่ | 11 สิงหาคม 2569 |
| ผู้จัดทำ | ทีมพัฒนาระบบจองห้องประชุม |
| สถานะ | สมมติฐานทั้ง 12 ข้อยืนยันแล้วโดยผู้ว่าจ้าง (ดู [`to-questionnaire-booking-assumptions.md`](../../to-questionnaire-booking-assumptions.md) และหัวข้อ 2.5) ASM-11 มีเงื่อนไขเพิ่มเติม — ยังไม่มีเอกสาร TOR ฉบับทางการ แต่ขอบเขตในบทที่ 1 ได้รับการยืนยันตรงจากผู้ว่าจ้างแล้ว (ASM-01) |

## ขอบเขตของเอกสารชุดนี้

เอกสารชุดนี้กำหนดว่าระบบจองห้องประชุมต้องทำอะไรได้ ต้องทำได้ดีเพียงใด และจะตรวจรับอย่างไร โดยแปลงมาจากสองแหล่งคือ `CONTEXT.md` ซึ่งเป็นภาษากลางของโดเมน และ `docs/adr/` ซึ่งเป็นข้อตัดสินใจเชิงสถาปัตยกรรมที่ตกลงไว้แล้ว ทุกข้อกำหนดในเอกสารมีรหัส เขียนเป็นเงื่อนไขที่ชี้ผ่านหรือไม่ผ่านได้ และสอบทานกลับไปยังข้อ TOR ได้ในบทที่ 7

เอกสารนี้ไม่ครอบคลุมการออกแบบภายในระบบ เช่น โครงสร้างโค้ดหรือ schema จริงของฐานข้อมูล

## วิธีอ่านเอกสารตามบทบาท

| คุณคือ | อ่านตามลำดับนี้ |
|---|---|
| ผู้ว่าจ้าง / เจ้าของงาน | บทที่ 1 → หัวข้อ 2.3 (กระบวนการ As-Is และ To-Be) → หัวข้อ 2.5 (สมมติฐานที่ต้องยืนยัน) → บทที่ 7 |
| ทีมพัฒนา | บทที่ 3 → บทที่ 5 → บทที่ 6 → หัวข้อ 2.4 (ข้อจำกัด) |
| ผู้ทดสอบ / ผู้ตรวจรับ | บทที่ 7 → บทที่ 4 → ตาราง Use Case Description ในบทที่ 3 |
| เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล | หัวข้อ 5.3 (คอลัมน์ข้อมูลส่วนบุคคล) → หัวข้อ 5.5 → หัวข้อ 4.5 |

## สิ่งที่ต้องได้ข้อยุติก่อนเริ่มพัฒนา

1. ~~**เอกสาร TOR ฉบับจริง**~~ — ยังไม่มีเอกสาร TOR ฉบับทางการ แต่ผู้ว่าจ้างยืนยันตรงแล้วว่าขอบเขตในบทที่ 1 ถูกต้อง (ASM-01) หากได้ TOR ฉบับจริงในภายหลัง ยังต้องนำมาจับคู่รหัสในหัวข้อ 7.1 ใหม่อีกครั้งเพื่อความครบถ้วน
2. ~~**สมมติฐาน 12 ข้อในหัวข้อ 2.5**~~ — ยืนยันครบแล้วโดยผู้ว่าจ้าง (ดู [`to-questionnaire-booking-assumptions.md`](../../to-questionnaire-booking-assumptions.md)) ASM-11 มีเงื่อนไขเพิ่มเติม: ไม่มีหน้า login ในเฟสนี้ แต่มีแผนเพิ่มระบบยืนยันตัวตนในอนาคต
3. **การรับทราบความเสี่ยงจากการไม่มีระบบยืนยันตัวตน** — เป็นเงื่อนไขของ `NFR-SEC-04` ก่อนติดตั้งใช้งานจริง (ที่มา: ADR-0002) — ยังไม่ได้ถามในรอบนี้ ควรยืนยันแยกก่อนติดตั้งใช้งานจริง
